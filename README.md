## 1. Descrição do Modelo de Negócio
O Pixel Rent é um sistema de gerenciamento de locação de jogos físicos e digitais, inspirado no conceito das locadoras tradicionais e em plataformas de gerenciamento de catálogos. O sistema permite organizar os jogos por plataforma, controlar a disponibilidade das mídias, cadastrar clientes e registrar locações e devoluções.
